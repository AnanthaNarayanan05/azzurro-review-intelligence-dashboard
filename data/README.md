# Data folder

| Folder | Purpose | Tracked in Git? |
|---|---|---|
| `sample/` | **Synthetic** demonstration data, generated by script and labelled as synthetic. Not real guest reviews. | Yes |
| `raw/` | Authorised review exports as received (e.g. Booking.com CSV/XLSX). | **No** – private |
| `processed/` | Local SQLite database and any derived files. | **No** – private |
| `uploads/` | Temporary files from the import wizard. | **No** – private |

Never place real review data in `sample/`.
